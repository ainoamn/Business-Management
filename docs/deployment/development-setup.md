# بيئة التطوير

اتبع README. منافذ المضيف: web=3000 وapi=4000 وpostgres=55432 وredis=56379 وS3=59000، جميعها loopback. اختيرت منافذ البيانات المنفصلة بعد اكتشاف خدمة Redis أخرى على المنفذ القياسي؛ لم تتغير الخدمة القائمة. غير منافذ compose وعناوين `.env` معاً إذا تعارضت مع خدمات أخرى؛ عند تغيير منفذ API حدّث Next proxy أيضاً، وعند تغيير web حدّث WEB_ORIGIN.

Postgres init script ينشئ work_app مرة عند أول volume. تغيير كلمة المرور في `.env` بعد إنشاء volume لا يغيرها في قاعدة البيانات؛ نفذ ALTER ROLE بعملية آمنة بدلاً من حذف البيانات. Redis وSeaweedFS يستخدمان كلمات المرور المحلية المولدة. weed mini ينشئ bucket المحددة على التشغيل؛ لا توجد واجهة إدارة مخزن مكشوفة على المضيف.

`pnpm infra:down` يوقف خدمات المشروع دون إزالة volumes. لا توجد أوامر تلقائية تمس بيانات المشاريع الأخرى أو تعيد ضبط محرك Docker.
