# بوابة الإنتاج

لم تُنشأ بيئة إنتاج ولم يُنشر التطبيق. يلزم إكمال مراحل المنتج وقبولها أولاً.

قبل الإطلاق: HTTPS وDNS وreverse proxy وtrusted proxy مضبوط؛ فصل حساب migrations؛ IAM S3 محدود وbucket خاص؛ Redis محمي مع TLS؛ أسرار من secret manager؛ cookies وCSRF وMFA وrate limiting؛ مراقبة وتدقيق وتنبيه؛ backups واستعادة مجربة؛ سياسة احتفاظ؛ بريد موثق؛ مزود دفع مفعل ومختبر؛ مراجعة أمنية وقانونية.

إطلاق تدريجي مع migrations متوافقة للخلف وrollback للتطبيق دون إسقاط بيانات. لا تستخدم حساب تخزين admin محلي أو حساب مهاجر PostgreSQL في التطبيق. لا توجد ضمانات سعة أو SLA قبل الاختبار والقياس الفعلي.
