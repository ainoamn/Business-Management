# تجربة النظام ببيانات مستقلة

نفذ من مجلد المشروع: `pnpm db:local` ثم `pnpm db:migrate` و`pnpm build` و`pnpm demo:seed`.

ينشئ الأمر قاعدة PostgreSQL جديدة باسم `work_demo_<معرف عشوائي>`، ويطبق المهاجرات ثم ينشئ البيانات عبر API الحقيقي. لا يفرغ قاعدة الموقع ولا يعيد ضبط مستخدميها. يُرفض التشغيل إذا لم تكن البيئة تطويرية وقاعدة البيانات محلية.

تتضمن التجربة مؤسسة موسومة `[DEMO]`، مالكًا ومديرًا عامًا ومدير إدارة وموظفًا ومحاسبًا، وهيكلًا وفريقًا ومشروعين وست مهام واجتماعين ومستندًا نصيًا آمنًا وميزانية ومصروفين وإشعارات تعيين فعلية. يوجد مشرف منصة تجريبي مستقل في قاعدة التجربة. عقد التدريب صفري القيمة ولا يمثل تحصيلًا ماليًا، ولا تُفعل خدمة AI أو مزود دفع خارجي ببيانات وهمية.

يعرض الأمر معرف التجربة ومكان ملف الدخول، دون طباعة كلمات المرور. افتح `.local/demos/<المعرف>/access.json` محليًا لمعرفة الحسابات وكلمات مرورها العشوائية. هذا الملف يتضمن أسرار تجربة محلية وهو متجاهل في Git؛ لا تنشره. لا توجد كلمة مرور افتراضية ثابتة.

ابدأ التجربة بالأمر `pnpm demo:start <المعرف>`. افتح `http://localhost:3100/app` للعمل أو `/platform` للإدارة. تعمل API التجربة على 4100 وتستخدم قاعدة التجربة فقط، وتبقى منافذ الموقع المعتادة 3000 و4000 منفصلة. يتوقف المشغل إذا كانت منافذ التجربة مستخدمة. يستخدم اسم المضيف localhost لعزل كوكيز التجربة عن الموقع المعتاد على 127.0.0.1. أوقفه بـ Ctrl+C؛ تبقى البيانات لتجربتها لاحقًا.

البريد في صندوق تطوير محلي، وتُحفظ مستندات التجربة في مجلدها داخل `.local/demos`. لا تعتمد هذه البيئة لاختبار بريد أو دفع خارجي. كل تنفيذ لأمر الإنشاء يعطي تجربة جديدة؛ لا يوجد تنظيف آلي يمس تجارب محفوظة أو قواعد عملاء.
