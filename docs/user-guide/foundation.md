# استخدام صفحة التأسيس

افتح الصفحة الرئيسية بعد تشغيل web وapi والخدمات. تعرض أربع حالات اتصال من الخادم. اضغط إعادة الفحص لتحديثها؛ يوجد cache لخمس ثوانٍ لتجنب تكرار probes.

زر English يغير اللغة والاتجاه، وزر المظهر يبدل الألوان. يحفظ المتصفح هذين التفضيلين فقط. رابط API يفتح Swagger المحلي، وفحص الخادم يعرض liveness.

لا توجد حالياً واجهة تسجيل أو بيانات مستخدم أو CRUD أعمال. لن تطلب هذه الصفحة كلمة مرور أو مفتاح تكامل، ولن تعرض مؤشرات نجاح زائفة إذا كانت الخدمات متوقفة.
