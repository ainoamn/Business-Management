# الأدوار المخططة

دورا Platform Super Admin وPlatform Support منفصلان عن عضويات المؤسسة، ولا يمنحان وصولاً تلقائياً لمحتوى العملاء.

قيم عضوية المؤسسة المقيدة في قاعدة البيانات: Organization Owner، Organization Admin، General Manager، Department Manager، Project Manager، Team Leader، Employee، Accountant، Requester، External Client، Auditor، Guest.

المخطط يحمل دوراً تأسيسياً واحداً لكل عضوية؛ هذا ليس RBAC مكتملاً. المرحلة الثالثة تستبدل ذلك بعلاقات Role/Permission/MembershipRole ودعم النطاقات، وتختبر عدم تصعيد الامتيازات والدعوات. Account واحد يمكنه عضويات متعددة، وبأدوار مختلفة.
