# مطابقة الأمر الهندسي مع التنفيذ الفعلي

التاريخ: 2026-11-04

الحكم: **الخطة لم تُنفَّذ كاملة.** المستودع يحتوي منتجاً أساسياً قابلاً للتشغيل محلياً، ولوحة منصة، ومساحة عمل للمؤسسة تغطي جزءاً كبيراً من الوحدات. لا يوجد إطلاق إنتاجي مكتمل، ولا يجوز اعتبار المنصة جاهزة للبيع أو للاستخدام اليومي لكل ما ورد في الأمر الهندسي.

المرجع التشغيلي المفصل: [PROJECT_STATUS.md](../../PROJECT_STATUS.md). هذه الوثيقة لا تعيد ادعاء نجاح اختبار لم يُشغَّل في هذه الجلسة.

## ما هو موجود في الكود

- Monorepo بـpnpm: `apps/web` (Next.js Pages Router) و`apps/api` (NestJS) و`packages`.
- PostgreSQL وPrisma وmigrations وعزل مؤسسات، وRedis وBullMQ وS3 في التركيب المحلي وDocker Compose.
- واجهة عربية/إنجليزية وRTL/LTR ومظهر فاتح/داكن.
- حسابات المؤسسة: تسجيل ودخول وتأكيد بريد واستعادة كلمة مرور ودعوات وأدوار ونطاقات وفروع وإدارات وأقسام وفرق.
- مشاريع ومهام وحالات وكانبان وتقويم وخط زمني وجانت ووقت واجتماعات وطلبات وموافقات وميزانيات ومصروفات ومستندات وأتمتة وبحث وتقارير وتصدير.
- مساعد ذكاء اصطناعي بطبقة مزوّد وموافقة وحصص ومسودات تحتاج تأكيداً بشرياً. لا يُفعَّل مزوّد حقيقي دون مفتاح يضيفه مشرف المنصة.
- لوحة `/platform` للمشرفين والباقات والاشتراكات والفواتير والقيود اليدوية والصفحات والإعدادات والتدقيق والمراقبة.
- اختبارات وحدة وتكامل وواجهة موثقة في حالة المشروع السابقة. Docker Desktop كان يتعطل، لذلك Redis وS3 لم يكونا جاهزين في تلك البيئة.

## ما لم يُنفَّذ أو لم يُقبل تشغيلياً

| مطلب الخطة | الحالة |
| --- | --- |
| صفحات تسويقية مستقلة: المزايا والحلول والقطاعات والأسعار والقوالب ومن نحن والأمان والخصوصية والشروط والمساعدة واتصل بنا | غير موجودة كمسارات مستقلة. الصفحة العامة الحالية صفحة تأسيس وحالة خدمات. المحتوى العام يمر عبر صفحات `/content/[slug]` بعد نشرها من لوحة المنصة. |
| دفع إلكتروني وويب هوك وتجديد تلقائي وكوبونات محصلة | غير منفذ. القيود والفواتير يدوية وليست تحصيلاً مصرفياً. |
| MFA واستعادة كلمة مرور المشرف بالبريد الخارجي | غير منفذ. البريد المحلي Outbox، وSMTP غير متحقق منه. |
| SMS وWhatsApp وإشعارات المتصفح Push | غير منفذة. الإشعار داخل التطبيق وSSE موجودان. |
| تكاملات التقويم وDrive وTeams والمحاسبة والموارد البشرية وSSO | واجهات مستقبلية فقط، وليست تكاملات عاملة. |
| فحص برمجيات ضارة فعلي للملفات | الوضع الافتراضي `none`. ClamAV غير موصول بخدمة مفحوصة. |
| Redis وS3 وDocker في بيئة المستخدم الأخيرة | غير جاهزة. PostgreSQL المحلي كان البديل. |
| اختبارات أداء واستعادة نسخ واختبار اختراق وامتثال قانون البيانات | غير مكتملة. الوثائق تصف المطلوب ولا تثبت الامتثال. |
| تطبيق هاتف أصلي | غير مطلوب في النسخة الأولى؛ الواجهة متجاوبة فقط. |
| نشر إنتاجي كامل للخادم وقاعدة البيانات | غير منفذ. نشر Vercel يستضيف واجهة Next.js فقط. |
| Argon2id تحديداً | كلمات مرور المشرفين تستخدم scrypt. هذا تخزين مقبول لكلمات المرور، وهو ليس Argon2id المذكور في الأمر. |
| محافظ المشاريع كوحدة مستقلة مكتملة | التقدم والتقارير يغطيان المشاريع. مسار `/app/portfolios` المستقل غير مذكور كوحدة مغلقة في حالة المشروع. |
| بيانات تجريبية Seed إنتاجية | مرفوضة عمداً. لا حسابات افتراضية. |

## صفحات التطبيق الموجودة

المسارات العامة: `/` و`/login` و`/register` و`/forgot-password` و`/reset-password` و`/verify-email` و`/accept-invitation` و`/content/[slug]` و`/admin` و`/platform`.

مساحة العمل مسار واحد ديناميكي `/app/[[...path]]` ويعرض، حسب الصلاحية: لوحة التحكم، المهام، المشاريع، الفروع، الإدارات، الأقسام، الفرق، الأعضاء، الدعوات، الأدوار، التقويم ضمن المهام، الاجتماعات، المستندات، الوقت، الميزانيات، المصروفات، الطلبات، الأتمتة، التقارير، البحث، المساعد، الإشعارات، وإعدادات الملف والجلسات والمؤسسة والذكاء الاصطناعي.

هذه الصفحات ليست قشرة فارغة في الكود؛ عملياتها تمر عبر API الخادم. على Vercel بدون خادم API تبقى الواجهة ظاهرة وتفشل عمليات الحفظ إلى أن يُضبط `API_ORIGIN` وتُنشر الخدمات.

## قرار هذه الجلسة

رُفع المصدر إلى Git، ونُشرت واجهة Next.js على Vercel حتى تفتح الصفحة العامة عبر HTTPS. هذا لا يعني أن المنصة التجارية اكتملت، ولا أن الدفع أو الذكاء الاصطناعي أو قاعدة البيانات يعملان على نطاق Vercel.
