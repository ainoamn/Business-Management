# رحلات القبول

1. المالك يسجل مؤسسة → يتحقق البريد → ينشئ إدارة وفريقاً → يدعو موظفاً → يضبط صلاحياته.
2. المدير ينشئ مشروعاً ومهمة → يعين الموظف → الموظف ينفذ ويعلق ويرفع مستنداً → يرسل للمراجعة → صاحب صلاحية يعتمد ويغلق.
3. المستخدم متعدد المؤسسات يبدل العضوية → يرى بيانات النطاق الحالي فقط؛ تغيير المعرف يدوياً يعاد رفضه من الخادم وقاعدة البيانات.
4. المحاسب يطلب مصروفاً مرتبطاً بالمشروع → معتمد منفصل يراجع → يظهر التغيير في تقرير التكلفة.
5. المستخدم يطلب خطة AI → يشاهد مسودة ومصدرها → يراجعها ويوافق قبل حفظ أي بيانات.

هذه الرحلات مستهدفة للمراحل التالية، ولم تصبح قابلة للتنفيذ في الواجهة الحالية.
