## الإصلاحات المؤكدة

- مؤشرات اليوم تعتمد حدود اليوم في المنطقة الزمنية للمؤسسة، وتصنّف حالات المهام المخصصة حسب فئاتها؛ لا تُعد الحالات الملغاة أو النهائية مفتوحة أو متأخرة.
- أرشفة الإشعار واستعادته لا تحذفانه ولا تغيّران محتواه. الطلبات المكررة لا تكرر التدقيق. لا يستطيع مشرف المؤسسة تعديل إشعارات متلقٍ آخر.
- تحميل SDK الهوية بعد تحميل الصفحة، مع إعادة محاولة مكونات الهوية عند جاهزيته المتأخرة. لا تُعلَّق تهيئة الموقع على استجابة الخادم الخارجي.
- القائمة الجانبية على سطح المكتب قابلة للتمرير داخل مساحة العرض. وضع الهاتف مستقل.
- بيانات التجربة تشمل إعدادات المنصة منذ البداية، وتُستخدم واجهة مبنية مع وسيط API محلي مستقل بدل تعديل مسارات الواجهة أو ملفات TypeScript المولدة.
