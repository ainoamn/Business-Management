# سجل المحادثات التنفيذية — تشرين الثاني / نوفمبر 2026

هذا الملف يوثّق مسار العمل من أمر البناء الهندسي حتى الجولات اللاحقة، ويصحّح ما ورد في محادثات مبكرة أن النظام الداخلي غير موجود. المرجع الحي للحالة: [PROJECT_STATUS.md](../../PROJECT_STATUS.md). نتائج 11 تشرين الثاني في [verification-2026-11-11.md](verification-2026-11-11.md).

## 3 تشرين الثاني — التأسيس ولوحة المنصة

1. نُفّذ أمر البناء داخل المستودع: Monorepo وNext.js Pages Router وNestJS وPrisma وDocker وPostgreSQL وRedis وBullMQ وS3، مع وثائق المعمارية وCI. نجح البناء وLint وفحص الأنواع واختبارات وحدة وواجهة جزئية. قبول Docker والمهاجرة كان معلّقاً حينها بسبب تعطل Docker Desktop.
2. شُغّلت الواجهة محلياً بـHTTP 200 مع اللغة والمظهر والهاتف. الخادم وقاعدة البيانات كانا غير متصلين بسبب Docker.
3. بُنيت لوحة `/admin` و`/platform`: المشرفون والصلاحيات والباقات والاشتراكات والفواتير والقيود اليدوية والصفحات والإعدادات والتدقيق والمراقبة، مربوطة بـPostgreSQL. تفعيل المالك عبر `pnpm platform:bootstrap` دون كلمة مرور افتراضية.
4. صُوّرت شاشات الإدارة ببيانات اختبار معزولة. في ذلك اليوم كان النظام الداخلي للمؤسسات (المهام والمشاريع) ما يزال قيد البناء؛ هذا **لم يعد** وصف الحالة الحالية.

## 4–5 تشرين الثاني — مساحة العمل والنشر والهوية

- أُكملت مساحة العمل `/app`: الهوية والهيكل والمشاريع والمهام والاجتماعات والملفات والوقت والمالية والطلبات والأتمتة والبحث والتقارير والمساعد.
- رُفعت الواجهة إلى GitHub ونُشرت على Vercel: https://business-management-sigma.vercel.app.
- رُبط الدخول الموحّد BHD Identity (`bhd-work`)، مع جلسة على المضيف المنشور عند غياب `API_ORIGIN`.
- استُبدل شعار المنصة بعلامة BHD مع حرف **B**.
- أُغلقت خريطة الصفحات في الأمر الهندسي، وأُضيفت لوحة مؤشرات حسب الدور، وصفحة `/ai` العامة.

## 11 تشرين الثاني — الإشعارات والملفات والتحقق

- أرشيف إشعارات شخصي، ودفع متصفح مشفّر مع طابور، وسياسة ملفات المؤسسة، ومحوّل Twilio للرسائل مع موافقات وحدود.
- تحقق محلي موثّق: وحدات واختبارات API ومتصفح واستعادة وأداء عيّنة. Redis والطابور والتخزين الخارجي ما زالت غير جاهزة في `health/ready` المحلي عند غياب Docker.
- الإرسال الحي لـPush/SMS/WhatsApp والدفع الحي واستضافة API+DB مع الواجهة المنشورة لم تُنفَّذ في هذه الجولات.

## أين تدخل وكيف تستخدم المنصة الآن

| الواجهة | المسار | الدخول |
| --- | --- | --- |
| الموقع العام | `/` والمميزات والأسعار و`/ai` | بدون حساب |
| مساحة عمل المؤسسة | `/app` | تسجيل أو BHD أو دعوة |
| لوحة مالك المنصة | `/admin` → `/platform` | `pnpm platform:bootstrap` ثم دخول المشرف |

محلياً: `pnpm db:local` ثم `pnpm db:migrate` ثم `pnpm build` ثم `pnpm platform:bootstrap` ثم `pnpm dev`. الواجهة `127.0.0.1:3000` والخادم `4000`.

على Vercel تعمل الصفحات العامة وجلسة BHD على الواجهة. عمليات المؤسسة والإدارة التي تحفظ في PostgreSQL تحتاج خادم API مربوطاً بـ`API_ORIGIN`.
