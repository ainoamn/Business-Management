# معايير API

بادئة `/api/v1`، REST وJSON وUTF-8. GET للقراءة، ولا توجد عمليات كتابة عامة في مرحلة التأسيس. معرف `X-Request-ID` ينشأ في الخادم ويعود في الاستجابة.

خطأ اعتيادي: statusCode وmessage وrequestId. لا تعاد stack traces أو نصوص أخطاء SQL. استجابة readiness بعقد Readiness مستقل لتسهيل orchestration.

التحقق من المدخلات بـshared-schemas، رفض الحقول غير المعروفة، pagination افتراضياً 25 وحد أقصى 100. تعتمد API المستقبلية على userId من الجلسة الموثقة والتحقق من عضوية المؤسسة وصلاحية العملية داخل الخدمة. إخفاء زر لا يشكل حماية.
