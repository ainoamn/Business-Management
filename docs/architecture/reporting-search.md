# البحث والتقارير

البحث من /app/search يعيد مجموعات محدودة حسب نوع المورد، مع تصفح مستقل عند اختيار النوع. يعاد استخدام مرشحات المشاريع والمهام والاجتماعات والطلبات والمستندات والمالية والأتمتة نفسها؛ لا يبحث حساب بلا صلاحية في وحدة أخرى. الأرشيف والملفات غير المكتملة مستبعدان، ولا تعاد مفاتيح التخزين أو محتويات الملفات أو الحقول المالية في نتائج البحث. يعامل البحث % و_ كحروف عادية. فهارس pg_trgm تدعم استعلامات ILIKE؛ البحث القصير قد يكون أقل استفادة من الفهرس، كما توضح [وثائق PostgreSQL](https://www.postgresql.org/docs/current/pgtrgm.html).

تقارير /app/reports تقاطع صلاحية المورد وصلاحية reports.read، وتضيف نطاق reports.export عند التصدير. ينفذ التجميع في قاعدة البيانات، وتبقى العملات منفصلة. نهاية الفترة غير مشمولة، ويظهر الحقل الزمني المستخدم. المقارنة تستخدم فترة سابقة مساوية في المدة. الإنجاز حسب تاريخ الإكمال، والتأخير وعبء العمل حسب موعد المهمة، والوقت حسب بداية التسجيل، والمصروف حسب تاريخه. تقرير عبء العمل يعرض أعداد المهام المفتوحة والساعات المقدرة، ولا يفترض سعة غير مسجلة أو يصنف الأشخاص.

التقارير الحالية: المهام والإنجاز والتأخير والموظفون والإدارات والمشاريع والمخصصات والمصروفات والوقت وعبء العمل والاجتماعات والقرارات وموافقات الطلبات والأتمتة. تقارير الاشتراكات وAI، والموافقات المجمعة عبر جميع الوحدات، تستكمل مع وحداتها.

التصدير POST محمي بـCSRF والهوية وحد المحاولات والتزامن. يقرأ حتى ١٠٠٠٠ صف لـExcel/CSV أو ١٠٠٠ لملف PDF من نطاق التصدير الفعلي، ويطلب تضييق المرشحات للنتائج الأكبر. يحتفظ Excel بالمبالغ كقيم نصية دقيقة، دون تحويل النصوص إلى صيغ أو روابط نشطة. يسبق CSV القيم الخطرة بعلامة نصية. يسجل طلب التصدير في سجل التدقيق.

ينشئ PDF جدولًا ونظرة مجمعة وفترات ومقارنة باللغة المختارة بواسطة Chromium. يُهرب النص، وتُعطل JavaScript وطلبات الشبكة وService Workers؛ لا تقبل الخدمة مسارًا أو URL من المستخدم. تضبط المدد والتزامن ويغلق المتصفح في النهاية. الإنتاج يحتاج Chromium متوافقًا مع Playwright وخطًا يدعم العربية. يمكن تعيين REPORT_CHROMIUM_PATH من إعدادات النشر. غياب العارض يعيد خطأ واضحًا ولا يدعي إنشاء ملف.

التحقق: اختبارات PostgreSQL وHTTP على بيانات مؤقتة مستقلة تثبت النطاق والحصة والتصفية والمقارنة والصيغ الآمنة ومحتوى workbook ووجود PDF فعلي. اختبار Chromium ينزل الملفين، يقرأ Excel، ويرفع PDF الناتج إلى المخزن الخاص ويعاينه فعليًا. فُحصت لقطات المقارنة وPDF بصريًا.
