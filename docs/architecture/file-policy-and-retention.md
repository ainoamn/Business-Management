# سياسة الملفات والاحتفاظ

تحتوي إعدادات المؤسسة `/app/settings` على سياسة ملفات فعلية. يحدد من يملك صلاحية `organization.manage` على مستوى المؤسسة حجم الملف والامتدادات المسموحة. تعرض الواجهة الحجم بالميجابايت، مع إمكانية ترك الحقل فارغًا لاتباع حد الخادم. لا يسمح النظام بتجاوز الحد العام أو إضافة امتداد غير مدعوم أو إفراغ قائمة الأنواع. الافتراضي يتبع حد الخادم ويسمح بأنواع المستندات الآمنة المدعومة سابقًا.

تطبق السياسة على المستندات الجديدة وعلى رفع إصدار جديد. يبقى التحقق من التوقيع وبنية الملف والحصة وصلاحيات المجلد والسجل قائمًا، وفحص البرامج الخبيثة عند تفعيل الماسح. تُقرأ سياسة المؤسسة بعد حجز قفل المستندات عند بدء الرفع، ثم مجددًا قبل اعتماد الملف بعد التخزين. إذا تغيّرت أثناء الإرسال وأصبحت تمنع الملف، لا يصبح الملف إصدارًا صالحًا وتُدرج مادته المخزنة في طابور التنظيف المعتاد. لا تتحرر المساحة المحجوزة حتى ينجح التنظيف الفعلي.

الإصدارات الصالحة السابقة لا تحجب بتضييق السياسة. إعادة محاولة طلب رفع سبق اعتماده تعيد إيصال العملية السابقة دون إنشاء إصدار آخر. تعرض واجهة استخدام المستندات الحد الفعلي وقائمة الأنواع المسموحة، وتستخدمها نافذة الرفع الجديدة لتصفية الاختيار. يظل الخادم المرجع الملزم للسياسة.

واجهتا `GET` و`PATCH /api/v1/work/organizations/:organizationId/settings/file-policy` تتطلبان إدارة المؤسسة. جسم التعديل `{version,maxFileBytes,allowedExtensions}`؛ `maxFileBytes:null` يعني اتباع حد الخادم. التعديل يستخدم رقم نسخة، ويرفض النسخ القديمة بالحالة 409، ويسجل `FILE_POLICY_UPDATED` في سجل التدقيق. تعديل إعدادات المؤسسة العامة لا يعدل السياسة؛ حقول السياسة لا تقبل في مسار التعديل العام. تحفظ المهاجرة `202611110004_organization_file_policy` القيم على إعدادات المؤسسة المعزولة بآليات RLS القائمة، مع قيود قاعدة البيانات على الحجم والامتدادات.

سياسة الاحتفاظ الحالية ظاهرة في الإعدادات: السجلات المؤرشفة والمستندات وإصداراتها تبقى محفوظة دون حذف نهائي تلقائي، وتستعاد بالصلاحيات القائمة. الملفات المؤرشفة تظل محسوبة من الحصة. سجلات التدقيق والدفتر المالي محفوظة للتتبع؛ تصحيح القيود المالية يتم بالعمليات العكسية المتاحة. تنظف مواد الرفع الفاشلة بصورة مستقلة. لا تعرض الصفحة زر حذف دائم أو تدعي وجود مدد احتفاظ مخصصة أو امتثال قانوني تلقائي.

تشمل اختبارات API خمس حالات ضمن مجموعة العمل الفعلية: صلاحيات الإدارة وحدود الأنواع والحجم وقيود القاعدة؛ رفض الحجم قبل حجز المساحة؛ تطبيق النوع على المستند والإصدار دون إخفاء القديم؛ تعارض النسخ وبقاء السياسة بعد تعديل إعدادات عامة؛ وتغيير السياسة أثناء التخزين مع رفض الاعتماد وإنشاء مهمة تنظيف. السجل `.local/test-file-policy-2.log` يشمل نجاح 112 حالة للمجموعة الأساسية. يوثق فحص المتصفح حفظ السياسة وإعادة تحميلها وعرض الهاتف من النماذج الفعلية.
