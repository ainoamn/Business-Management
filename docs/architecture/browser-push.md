# إشعارات المتصفح

توجد إدارة الأجهزة في `/app/notifications`. لا يطلب الموقع إذن الإشعارات تلقائيًا؛ يطلبه زر «تفعيل إشعارات هذا المتصفح». يلزم HTTPS في الاستضافة أو localhost للتطوير، ومتصفح يدعم Push API. على بعض الهواتف يتطلب المتصفح تثبيت الموقع كتطبيق.

يشغّل `pnpm push:setup mailto:operations@example.com` توليد مفاتيح VAPID ومفتاح تشفير بيانات الأجهزة إلى الملف الخاص المتجاهل من Git `.local/push-configuration.env`. لا يطبع الأسرار ولا يستبدل ملفًا موجودًا ولا يفعّل الإرسال تلقائيًا. انسخ قيمه إلى بيئة الخادم الخاصة ثم أعد تشغيل API. يلزم الاحتفاظ بالمفاتيح لاستمرار الأجهزة المسجلة؛ تغيير مفاتيح التوقيع يتطلب إعادة تسجيل الأجهزة. يشترك المتصفح بنفسه لدى خدمة الإشعارات التي يدعمها؛ لا يتطلب ذلك حساب SMS.

يحفظ الخادم عنوان الإرسال ومفاتيح الجهاز مشفّرة، ويربط التسجيل بالعضو والجلسة الحالية. الحد خمسة أجهزة نشطة للحساب. إلغاء الجهاز يمحو القدرة على الإرسال إليه، وإلغاء الجلسة يعطله. تغيير الحساب في المتصفح يمنع عرض إشعارات الحساب السابق. لا يحتوي الدفع على عنوان المهمة أو نصوصها؛ يتحقق عامل المتصفح من الجلسة الحالية ثم يطلب إذن عرض من الخادم الذي يعيد فحص صلاحية السجل. أرشفة الإشعار أو تعطيل الدفع يلغي الإرسال المنتظر. استعادة الأرشيف لا تعيد الإرسال.

طابور PostgreSQL يثبت مع الحدث في المعاملة نفسها. العامل يحجز كل محاولة بمهلة، ويفحص الوصول قبل إرسال HTTPS محدود المهلة مثبت العنوان لمنع الوصول إلى الشبكات الداخلية. قبول مزود الدفع لا يثبت قراءة الشخص للإشعار؛ وطلب إذن العرض لا يثبت أن نظام التشغيل عرضه. عند الشك الشبكي قد تتكرر محاولة التسليم؛ يمنع حجز العرض الذري عرض التسليم نفسه مرتين. لا يُعاد إرسال التسليم بعد نجاح حجز العرض إذا تعطل المتصفح قبل إظهاره.

التحقق المحلي يشمل التشفير والتوقيع الفعليين وعزل قاعدة البيانات وطابور التسليم مع مزود اختباري، واختبارات عامل المتصفح. لا يُعد ذلك إثبات إرسال حي عبر خدمة متصفح خارجية؛ يحتاج هذا التحقق مفاتيح تشغيل وتفعيل المستخدم على جهاز فعلي.

واجهات API تحت `/api/v1/work/organizations/:organizationId/push`: قراءة `config` و`devices`، تسجيل جهاز `POST devices`، إلغاؤه `DELETE devices/:id`، وطلب عرض مرة واحدة `POST deliveries/:id/display` بجسم `{}`. تتطلب الجلسة وCSRF للكتابة؛ لا تعيد الواجهات عنوان القدرة أو مفاتيح الجهاز.
