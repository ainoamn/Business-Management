# مسؤوليات الوحدات

التأسيس الحالي:

- `config`: تحقق صارم من متغيرات البيئة؛ لا تطبع الأسرار.
- `database`: دورة اتصال Prisma و`withOrganization` بسياق محلي للمعاملة.
- `infrastructure`: Redis، عامل BullMQ لاختبار التنفيذ، وفحص bucket عبر StoragePort.
- `health`: فحوص مجمعة محدودة المدة مع cache لخمس ثوانٍ ومنع ازدواج الفحص المتزامن.
- `common`: معرف الطلب وتنسيق الأخطاء دون تسريب الاستثناءات الداخلية.

وحدة platform الجديدة تتلقى معرف مؤسسة للإجراءات الإدارية المصرح بها بعد مصادقة مشرف مستقل، وتستخدم دوال metadata محددة دون تجاوز عام لـRLS. `withOrganization` واجهة داخلية لا تقبل userId موثقاً من العميل مباشرة. صلاحيات المؤسسات ونطاقاتها ستضاف قبل تعريض بيانات الأعمال.
