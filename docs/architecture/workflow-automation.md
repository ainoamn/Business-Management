# سير العمل الآلي

تُدار القواعد من /app/workflows. يتيح المصمم المرئي اختيار الحدث ونطاقه وإضافة إجراءات وشروط ALL/ANY وتفرعات وانتظار ونهاية. لا يقبل المحرك كودًا أو موافقة مالية أو حذفًا بوصفه إجراء أتمتة.

كل حفظ ينشئ إصدارًا ثابتًا: trigger وgraph وجداول normalized للخطوات والشروط والإجراءات. تعديل قاعدة نشطة يعيدها إلى مسودة ويلغي تشغيلات إصدارها غير المكتملة، ويحفظ الإجراءات المنفذة. التفعيل إجراء صريح يسجل هوية الحساب وصلاحياته الحالية، وتُفحص الهوية والصلاحيات والمورد عند كل خطوة. تعليق الحساب أو المؤسسة أو سحب الصلاحية يوقف التنفيذ. يستطيع المدير إيقاف القاعدة وأرشفتها واستعادتها.

تُكتب أحداث الأعمال في outbox داخل معاملة المورد نفسها. يلتقط العامل الأحداث والتشغيلات بدفعات محدودة باستخدام SKIP LOCKED وleases قابلة للاسترداد. الانتظار موعد محفوظ في قاعدة البيانات، ويستأنف بعد إعادة التشغيل. تُحفظ نتيجة الإجراء وإيصال منع التكرار وتقدم الخطوة داخل معاملة واحدة. القاعدة الواحدة لا تتكرر في السلسلة السببية نفسها، وهناك حد لعمق السلاسل والخطوات والأزمنة. تعيد الأعطال المؤقتة المحاولة بحد أقصى محدد.

تشمل الأحداث المهام والطلبات والمصروفات والمشاريع والاجتماعات. يُحسب انخفاض المخصص من المصروفات المعتمدة فعليًا، وتُربط تنبيهات التأخير بالموعد أو مرحلة الموافقة الحالية؛ تغييرها يلغي التنبيه القديم. تُراجع صلاحية قراءة المورد لكل مستلم إشعار. إرسال طلب أو مصروف للموافقة يعيد فحص صلاحيات صاحبه ولا يمنح اعتمادًا آليًا.

تُفرض حدود القواعد النشطة والتشغيلات من الباقة على الخادم. تُحسب الحصة عند بدء التنفيذ مرة واحدة، بما فيها التنفيذ الذي يفشل بعد البدء. إعادة المحاولة تحفظ الإيصالات والحصة. الفترات الشهرية مرتبطة بذكرى بدء الاشتراك، مع ضبط نهايات الأشهر والسنوات الكبيسة.

سجل التشغيل يعرض الحالات والأخطاء الآمنة والإجراءات والانتظار والإصدار. لا يعرض رموز leases، وتُحجب مراجع الموارد غير المتاحة للقارئ. فحص الشروط يقرأ البيانات فقط ولا يشغّل إجراءات. الأحداث والإصدارات والسجلات محمية بعزل المؤسسة والقيود المرجعية وسياسات RLS.

التحقق: اختبارات API فعلية للحصة والتزامن وانقطاع العامل وسحب الصلاحيات ومنع الموافقة الذاتية وحلقات التنفيذ، واختبار متصفح ينشئ قاعدة شرطية ذات انتظار ويثبت وصول إشعار واحد وسجل التنفيذ والإصدار واللغة والهاتف. يعتمد العامل الحالي على PostgreSQL؛ لا يتطلب Redis لتشغيل هذه الوحدة.
