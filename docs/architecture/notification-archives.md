# أرشفة الإشعارات الشخصية

أضيفت في 2026-11-11. يحتفظ `work_notifications.archived_at` بحالة الأرشفة، دون حذف السجل أو تغيير مصدره أو محتواه. يمنع trigger في قاعدة البيانات تعديل الهوية والمحتوى وتاريخ الإنشاء، ويسمح بحالة القراءة والأرشفة. صلاحيات work_app لا تسمح بالحذف أو TRUNCATE.

`GET /work/organizations/:id/notifications` يعرض الحالية افتراضيًا، و`view=archived` يعرض المؤرشفة. العداد غير المقروء يحسب الحالية فقط. تعليم الكل كمقروء يترك الأرشيف كما هو. الاستعادة تعيد حالة القراءة الأصلية، وقد تعيد إشعارًا غير مقروء إلى العداد.

`POST notifications/:id/archive` يقبل `{restore:false}` للأرشفة و`{restore:true}` للاستعادة. الطلبات المكررة آمنة؛ لا تكرر التدقيق إذا لم تتغير الحالة. تعتمد العملية على العضوية الحالية والمتلقي نفسه، ولا تمنح إدارة المؤسسة حق تعديل إشعارات الآخرين. معرف مؤسسة آخر أو إشعار متلقٍ آخر لا يتجاوز العزل. جميع العمليات تحتاج الجلسة وOrigin وCSRF.

القائمة مرتبة بتاريخ الإنشاء ثم المعرف، مع فهرس للمؤسسة والمتلقي والأرشفة والتاريخ. تتضمن أحداث SSE العدد الكلي الحالي إضافة إلى أحدث إشعار وغير المقروء، لتحديث القائمة بعد أرشفة إشعار قديم مقروء على جهاز آخر. يعاد التحقق من الجلسة والعضوية عند كل إرسال SSE.

تختبر مجموعة HTTP الأرشفة والاستعادة والطلبات المتزامنة واحتفاظ القراءة والعزل ومنع حذف السجل أو تزوير المحتوى. اختبار الواجهة يغطي الأرشيف والاستعادة والعربية والإنجليزية والهاتف؛ نتيجة كل جولة في سجل الاختبارات العام.

هذا المسار لا ينفذ إرسال Browser Push أو SMS أو WhatsApp؛ تبقى حالة مزودي القنوات الخارجية منفصلة عن الإشعارات داخل التطبيق.
