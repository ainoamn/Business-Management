# المعمارية الأمنية الحالية وحدودها

## تحديث: هوية إدارة المنصة

مصادقة المشرفين منفصلة ومنفذة: جلسات opaque، Cookie HttpOnly/SameSite وSecure خارج development، وCSRF مرتبط بالجلسة وOrigin موثوق وحد محاولات دخول في PostgreSQL. كلمات المرور scrypt N=2^17 وr=8 وp=1 مع salt عشوائي، وفق بديل scrypt في [مرجع OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html). لا يمثل ذلك شهادة امتثال.

إدارة حسابات المشرفين والأدوار مقصورة على المالك داخل الخدمة، وتُعاد قراءة صلاحيات الفاعل قبل الكتابة. تعطيل الحساب يبطل جلساته وتغيير كلمة المرور يبطل الجميع. لا حسابات افتراضية؛ CLI التهيئة تفاعلي ولا يمرر كلمة المرور في معاملات shell أو يكتبها إلى ملف.

دوال SECURITY DEFINER محددة لكشف بيانات تعريف المؤسسات فقط، وتتحقق من حساب منصة نشط وصلاحية صريحة، وتثبت search_path وتمنع EXECUTE للعامة. حساب التطبيق لا يملك BYPASSRLS. إيقاف المستخدم والمؤسسة مفروض أيضاً عبر سياسات RLS. لا يوجد وصول تلقائي إلى محتوى مهام أو مستندات العملاء.

القيود المالية وسجل التدقيق append-only لحساب التطبيق ومراجع المعاملات فريدة. النص المنشور يستخدم React escaping ولا ينفذ HTML/JavaScript.

ما يلي من المصادقة غير المنفذة يخص الآن هوية مستخدمي المؤسسات. MFA والاستعادة والبريد والتنبيهات الخارجية ما تزال غير منفذة لكلا نوعي الحسابات.

تم تنفيذ: أسرار محلية عشوائية وملف ignored؛ فحص بيئة؛ Helmet وno-store؛ CORS origin محدد؛ طلبات ذات UUID؛ تنسيق أخطاء لا يعرض stack؛ حساب PostgreSQL محدود؛ FORCE RLS؛ سياق مؤسسة محلي للمعاملة؛ تخزين S3 محلي خاص؛ منافذ الخدمات مربوطة بـloopback.

لم تُنفذ بعد: المصادقة، Argon2id، CSRF، جلسات cookies، MFA، recovery، RBAC/ABAC، rate limiting موزع، تحميل الملفات وفحصها، تنبيهات أمنية، إدارة الأسرار الإنتاجية. لا يمكن اعتبار النظام جاهزاً للإنتاج أو مطابقاً لـOWASP ASVS لمجرد وجود الأساس الحالي.

قبل endpoints الكتابة: جلسة opaque مخزن hash فقط، Cookie HttpOnly/Secure وSameSite مناسب، التحقق من Origin وCSRF token، انتهاء وإبطال، قيود محاولات الدخول في Redis. لا توجد tokens في localStorage؛ تستخدم الواجهة localStorage للغة والمظهر فقط.

قبل الملفات: تحقق من magic bytes وallowlist وحد الحجم والحصة وحالة الفحص والحجر وملكية المؤسسة قبل كل توقيع. قبل AI: استرجاع حسب صلاحيات الفاعل، تقليل البيانات، عزل السياق، مقاومة prompt injection وموافقة على التغييرات.

الإطلاق يحتاج HTTPS ومراجعة أسرار وصلاحيات وتدقيق مستقل واختبارات التهديدات. مراجعة المتطلبات القانونية العُمانية تقع مع مختص قبل الإطلاق؛ لا تدعي هذه الوثيقة تحقق الامتثال.
