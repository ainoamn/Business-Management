# النسخ والاستعادة

Volumes محلية مستمرة، و`pnpm infra:down` لا يحذفها. لا تستخدم `docker compose down -v` على بيانات تحتاجها. نسخة PostgreSQL ينبغي أن تُشفّر وتُنقل خارج الجهاز بصلاحيات منفصلة وسياسة احتفاظ معتمدة.

خطوات التشغيل: pg_dump بصيغة custom بواسطة حساب نسخ يقرأ البيانات المصرح بها؛ التحقق من exit code وحجم الملف وchecksum؛ تسجيل وقت النسخة؛ اختبار pg_restore في قاعدة منفصلة؛ تطبيق منح work_app وRLS والتحقق منها؛ ثم مقارنة أعداد السجلات ومهاجرات Prisma.

لا تستخدم إعادة توجيه binary في Windows PowerShell القديم؛ استخدم pg_dump -f داخل الحاوية ثم docker cp. credentials تمر عبر بيئة الحاوية، ولا تنشرها في الأوامر أو التقارير.

يحتاج تخزين S3 إلى نسخة منفصلة متسقة مع metadata، وRedis إلى تحديد ما هو قابل لإعادة البناء وما هو طابور دائم. حدد RPO/RTO مع مالك المنتج وقس زمن الاستعادة فعلياً. لم يُنفذ تمرين استعادة بعد، ولا توجد أرقام RPO/RTO مضمونة.
